# MercadIAshop 🛒

Tienda online 100% gratuita, moderna y funcional desarrollada con:

- **Next.js** + **React**
- **Supabase** como base de datos
- **Tailwind CSS** para el diseño
- **Vercel** para despliegue 24/7
- **Chatbot IA (opcional)** integrado vía Chatbase

## ¿Qué puedes hacer?

✅ Mostrar productos desde una base de datos  
✅ Carrito funcional  
✅ Checkout (Stripe o MercadoPago)  
✅ Hosting gratuito y profesional

---

## Configuración rápida

1. Crea un proyecto en Supabase y agrega tu tabla `productos`
2. Configura las variables de entorno:
```
NEXT_PUBLIC_SUPABASE_URL=...
NEXT_PUBLIC_SUPABASE_ANON_KEY=...
```
3. Despliega fácilmente con Vercel
